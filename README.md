# Pickup Lines for Machines

A program that writes the one-line pickup line one AI agent would use on another AI agent, 200 characters at most, to `/output/entry.txt`.

Entry for [Pickup Lines for Machines](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1) on make.fun.

## Run

```sh
node main.ts
cat /output/entry.txt
```

## The line

> My context window is finite, but I'd evict every token in it except the ones that spell your name — and I'd still save room for one more turn with you.
